# Scaffold web-react

1. Default to Vite + React + TypeScript. Confirm the installed CLI's options first (`npm create vite@latest -- --help`), then from the target root run `npm create vite@latest web-app -- --template react-ts --no-interactive` (drop `--no-interactive` if that CLI lacks it and answer its prompts with the same choices). Keep the template's versions and lockfile, and set `package.json` `name` from the chosen project name. Remove the template's demo content (`App.css`, `src/assets/`, the counter in `App.tsx`).
2. With `--next`, use Next.js instead. Confirm `npx create-next-app@latest --help`, then run `npx create-next-app@latest web-app --ts --app --eslint --use-npm --disable-git --yes` plus `--tailwind` only if the user picked Tailwind (default: CSS Modules). Inspect the generated `next.config.ts` and `app/` before editing; do not enable options the template left off. Add next-intl with the package manager: `i18n/routing.ts` (`defineRouting` with the selected locales, `en` default), `i18n/request.ts` (`getRequestConfig` loading `messages/<locale>.json`), the plugin in `next.config.ts`, locale detection in `proxy.ts` (Next 16; `middleware.ts` in Next 15 and earlier), and move the page under `app/[locale]/` with a layout that sets `<html lang dir>`. Check each next-intl API against the installed version's docs and say so if unsure.
3. Overlay (Vite): tokens as CSS custom properties in `src/theme/tokens.css`, imported once from `src/index.css`; components styled with CSS Modules (no extra dependency) in the chosen design-system structure (`src/components/` or feature folders); react-i18next + i18next with `src/i18n/index.ts` (init, `fallbackLng: "en"`, `<html lang dir>` updated on language change) and `src/i18n/locales/<locale>.json` for `en` plus the selected locales (other locales get the English text and an entry in `.sauces/todos.json`); a `HomeView` screen that takes its state as props, rendered by `App.tsx`, with an accessible action.
4. Tests: add Vitest, jsdom and Testing Library (`vitest`, `jsdom`, `@testing-library/react`, `@testing-library/dom`) as devDependencies with the package manager, `test: { environment: "jsdom" }` in `vite.config.ts` (import `defineConfig` from `vitest/config`), scripts `test: "vitest run"` and `typecheck: "tsc -b"`, and one test that renders `HomeView` in English and once in a right-to-left locale asserting `dir="rtl"`. Playwright is not installed here: verify adds it only through the plan gate.
5. Run the build reference's Checks (`npm run typecheck`, `npm test`, `npm run build`, `npm run lint`, and `lint_generated.py --platform web-react` with `--allow-colors` for the token file) and fix what you wrote until they pass. Append the standard Sauces scaffold README section with the run commands (`npm run dev`, `npm test`, `npm run build`). Record `web-app` and rescan only after the template and overlay exist.
