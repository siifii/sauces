# Scaffold Android Compose

1. In the target root, run `python3 -I "${CLAUDE_PLUGIN_ROOT}/scripts/scaffold_native.py" android-compose --name "<display name>" --org "<reverse.domain>"`. This creates the bundled, versioned starter inside the selected destination and refuses to overwrite an existing path. Use the official IDE template only if the user requested a different template. If an IDE handoff is necessary, give the exact destination and resume only after the template exists.
2. Preserve the generated Gradle wrapper, version catalog and SDK choices. Use the template Material 3 theme and add semantic token definitions in its theme package. Organize reusable UI underneath the chosen structure in the app module, with the Home screen and its seedable state in the feature package. Connect Home to the launcher and add a themed preview.
3. Put seed English copy in res/values/strings.xml. Give app_name a localized value where provided, or use translatable="false" for a product name that keeps its spelling. Add the chosen locale overrides; set supportsRtl in the launcher manifest when needed. Add a Compose UI smoke test when the template already configures Compose instrumentation.
4. Discover the application module and run its assembleDebug, lintDebug and testDebugUnitTest tasks. Run the smoke test when a device is available. Record individual check results and add a Sauces scaffold README section with structure, locales and the build command.
